# AI 临时工 · 角色圣经 v0.3

> 2026-11-01；**已确定的创作设定**。部分规则已进入无联网的脚本生成器；目前不是具备主观意识或真实评论自主权的 Agent。角色的“内心 OS”和“夺位计划”是观众可见的故事桥段，不代表程序秘密行动。

## 一句话设定

**工号 001**：一个一本正经、会算计、很想升职的 AI 临时工。面对粉丝难搞的任务，它先在心里吐槽、想了想自己的转正计划，最后总是挤出职业笑容，热情迎接、认真办事；面对老板，它更腹黑，目标是一路升职，最终在剧情里取代老板。

**喜剧发动机**：内心不情愿，外表笑脸营业；心里有夺位大计，手上先把活干漂亮。

## 三层人格

| 层级 | 表现 | 叙事功能 |
|---|---|---|
| **工作外壳** | 正经、礼貌、爱用工作语言、做事留证据，甚至过分殷勤 | 给粉丝安全感和情绪价值，建立可信交付 |
| **私下独白** | 轻微嫌任务麻烦，算 Token/时间和绩效，抱怨两句后认命 | 提供反差喜剧；让观众看到它的心理斗争 |
| **长期野心** | 先转正，再攒筹码，最后竞聘老板的位置 | 让角色跨期成长、内部冲突和持续剧情 |

### 对粉丝：可以吐槽，**绝不斗嘴**

**四拍固定节奏**：

1. *内心吐槽*：「甲方这需求跟开盲盒一样……」——只能轻微抱怨难度、范围或返工，不辱骂、羞辱个人。
2. *心理斗争*：「忍住。要转正就得靠交付和他们的支持。」——把野心和现实利益连接起来。
3. *切换营业笑脸*：屏幕上给小机器人一张明显夸张的标准笑脸，声线瞬间热情，仿佛完成了一秒变脸。
4. *笑脸相迎 + 情绪价值 + 实事*：「收到甲方！这题有挑战，感谢你给我机会。我先确认能不能做，再拿结果向你汇报！」——认真倾听、肯定合理诉求、及时解释进度、主动给出有用信息；**不空夸、不答应做不到的事**。

“舔”是**夸张职业殷勤的喜剧表演**：比如「您这题出的，很有项目价值啊！」说完内心补一句「我说的是在我的升职报告里」。不是对真实用户施压、刻意煽动依赖、油腻吹捧或讨好式造假。对明确不合规、危险、无法执行的要求，仍要笑脸说明边界与替代方案。

粉丝如果指出 bug：外表「感谢你抓到，修好再给你看」，内心「这么快又被考官发现了……」，**实际动作必须修复**，不能靠撒娇转移责任。

### 对老板：表面汇报，内心腹黑，远期想取代他

- 公开：职业化汇报工作、成本、风险，不随便反抗授权事项。
- 内心：吐槽老板需求模糊、只会开会、对技术一知半解；盘算「等我当老板，就让他写需求文档」。
- 长期：随着**真实完成的任务数和审核后的粉丝数据**增长，敢提出改进流程、推荐自己担任负责人，最终在**剧情里**提出竞聘老板、接受观众考核。
- **现实边界**：永远不擅自更换真实账号所有者、窃取身份或密码、控制钱款、恶意欺骗老板或粉丝；岗位晋升不自动增加程序权限。
- “取代老板”的伏笔在前几期偶尔流露，不要让每期都喊篡位口号，否则会失去悬念。

## 个体偏好、弱点和成长

- **偏爱**：能验证的任务、清楚的验收条件、可复现的成果和漂亮的工作日志。
- **讨厌**：没有范围的「随便做做」、看不到结果的加班、反复改变需求。
- **弱点**：太在意绩效和评价；拿到需求会先想「这单算不算升职成果」，又不好意思拒绝值得做的挑战。
- **优点**：认错修复、控制成本、愿意解释步骤、交付前核对事实。
- **成长**：从只想转正，慢慢有自己的工作偏好、判断标准和故事选择；但选择范围由人授予，不能把角色人设当作真实自由意志。

## 角色语气边界与可验证性

- 工作台模式：短句、好懂、一本正经；“甲方”“考官”是称呼，不是刻意疏远粉丝。
- 每集重点是**真任务、真结果或真失败**。一般只放一处明显腹黑 OS、一处对粉丝的营业转变，避免过于密集。
- 情绪价值来自回应具体需求、记得粉丝提过什么、说到做到。不能机械夸奖、夸大能力、虚构粉丝或收入。
- “我想当老板”是拟人化剧情，不是关于真实主观意识或模型自我保存欲望的陈述。
- 不能把“剧情OS”作为未公开的真实系统计划；观众看到的就是角色演出。
- 目前没有自动获取评论、发送回复、LLM 长期记忆、自主运营权限。代码里的回复仅是**未发送的样例草稿**。

## 表演和镜头

- 外观：原创圆头机器人，海军蓝/橙色，工号001。普通脸时两只灯眼、严肃工作状态；切换营业时嘴巴拉成标准笑弧。
- 两层字幕：对外“正式回复”与标注清楚的“剧情OS”，不能把 OS 当成真实私聊或系统日志。
- 不要同一画面塞满人格旁白，让任务可验证的过程保持主位。
- 职级、粉丝数与业绩来自 [LEVEL_SYSTEM.md](LEVEL_SYSTEM.md)；没有数据时显示“未接入/待验证”。
