# 工作路线与验收门槛

## M0 · 可靠工程起点（v0.1）

- [x] 持久化仓库、明确可追踪范围与非目标
- [x] 输入检查与真正可打开的 HTML 交付生成器
- [x] 交付 SHA-256、日志、episode.json、SRT
- [x] 离线竖屏视频渲染代码及单元测试
- [ ] 用户设备/真实浏览器可用性测试
- [ ] 真实创意/视觉质量验收

## M1 · 值得观看的样片

- [ ] 在目标设备打开网页与视频并检查字幕、时长、画面
- [ ] 增加可靠 TTS 配音及显式成本记录（不默认购买服务）
- [ ] 将工作过程转化成带节奏的短视频，避免纯文字卡片
- [ ] 完成 2～3 条不同任务的可复现样片
- [ ] 用户确认角色、美术及内容方向

## M2 · 真正智能的任务执行器

- [ ] 只在批准预算内选择适用 LLM/API
- [ ] 增加受限工具调用、人工审批与可审计任务日志
- [ ] 让 Bot 对失败/完成产生可验证结果，而不是固定话术
- [ ] 增加多期记忆和任务选题的最小数据模型

## M3 · 真实账号验证（前两阶段通过才启动）

- [ ] 注册并授权账号（需用户完成身份相关步骤）
- [ ] 正确 AI 标识、发布前审核与素材权益检查
- [ ] 小批量真实发布并收集可靠的观看与评论数据
- [ ] 在接口权利明确前，不做未授权的自动读评/回评/代发
- [ ] 依据真实数据决定继续、调整或停止
